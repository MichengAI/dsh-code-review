# I010 对齐 Codex 纯命令模式与移除全局 Tool

- **状态**：进行中
- **负责人**：维护者
- **更新时间**：2026-11-10 11:30（Asia/Shanghai）

## 目标与业务边界

1. **核心目标**：
   - 彻底解决 Issue #3 反馈的「Agent 会自动触发 review」问题。
   - 对齐 OpenAI Codex 官方架构设计（`disable-model-invocation: true` 理念），将代码审查定位为由用户主动发起的独立质量门禁。
   - 移除注册到 `ctx.tools` 的全局模型工具 `dsh_code_review`，主 Agent 上下文工具箱保持纯净，杜绝主模型在日常编写代码、修 bug 期间自发调用审查。
   - 改造 `/review` 斜杠命令：命令 handler 直调底层审查流水线（范围交互选择 -> 原生 spawn 子 Agent -> Codex rubric 审查 -> 结果持久化与渲染），直接返回审查报告卡片。

2. **业务边界**：
   - 不改动 Codex 评分尺（`assets/codex/review/rubric.md`）与子 Agent 隔离沙箱逻辑。
   - 保持用户交互与命令体验完全兼容：`/review`、`/review-status`、`/review-cancel` 命令语义不变。
   - 保持 8 门官方语言的本地化输出和界面提示。
