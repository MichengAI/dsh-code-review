## 目标与边界

用户已选择对齐 Codex 交互式 `/review`，而非 CLI `codex review`。复用 DSH 原生问题服务、当前 Agent followup 和 spawn 子 Agent，不新增界面或 Agent 生命周期实现。完整 Codex rubric 原文不改动。

## 已完成

- 空 `/review` 经当前 Agent 的 `code_review` 调用原生 `userQuestions.ask`，提供基准分支、未提交更改、某次提交、自定义要求四项。
- 分支展示本地及远程引用（最多 100 项），提交展示最近 30 项；支持自由输入未列出的引用，Git 验证引用且不通过 shell。
- 非空尾随文本完整进入 reviewInstructions，不解析 CLI 选项或保留词；状态、取消迁移为 `/review-status`、`/review-cancel`。
- 分支审查使用 merge-base 到工作区，包含未提交净更改；提交审查仍固定历史快照。
- 选择和审查共用取消与卸载生命周期；无回答器、跳过或取消不能默认开跑；选择取消不覆盖上次报告。
- 新增精确版本 `@deepseek-ai/dsh-user-questions@0.1.5-rc.2` peer，沿用宿主服务。
