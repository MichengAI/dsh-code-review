## 目标与边界

用户要求参考专家插件，使用宿主原生方式启动和展示子 Agent。替换底层 agents.create 和自定义前端卡片，不修改专家插件、simplify 或官方宿主。保留完整 Codex rubric、冻结快照、输出校验和旧报告恢复。

## 实现

- `/review` 参考 simplify，通过当前 Agent 的 followup 持久入队并唤醒主会话。
- `code_review` 工具参考 summon_expert，通过 subagents.start('spawn')、run.result、run.dispose 执行委派和收尾。
- 原生 provider 负责子会话身份、父子关联、descriptor/catalog 及开始/结束事件；不再自行创建、驱动和解析子会话 turn。
- 使用原生 toolFilter 和 persona；在同步 agent/created 通知配置本次子作用域的冻结读取工具与 guard。AsyncLocalStorage 区分并发创建调用，避免误限制其他专家；不自建 provider。
- 删除 I003 的前端模块、卡片、构建器及专属依赖；主会话通过标准工具结果和模型回答展示报告。
- 取消沿用原生生命周期，去掉额外 180 秒强制终止，保留显式取消与插件卸载收敛。
