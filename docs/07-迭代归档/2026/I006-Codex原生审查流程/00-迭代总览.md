## 本机工具作用域修复

用户实际运行报 `tools.restrict() names unknown global tool "subagent"`。回归夹具复现：父子 Agent 都把 subagent 注册在本地作用域，全局目录中没有该工具；旧逻辑读取父作用域可见工具，错误地将其传给子作用域的 restrict。

修复只向 restrict 传递全局注册项，局部及后续注册项仍由执行 guard 拒绝；保留 Git 和其他原生检查工具。补齐实际宿主的 subagent_fork、read_image 名称。已验证修复前同错、修复后审查启动并执行 Git diff，局部委派仍被拒绝，40 项源码测试通过。此修复随 `fix: handle agent-local tools in review restrictions` 提交，原有三个提交保持不变。
