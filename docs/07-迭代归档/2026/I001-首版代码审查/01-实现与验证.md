# I001 实现与验证

更新时间：2026-09-13 11:55（Asia/Shanghai）

## 实现

- `src/index.ts` 注册原生 `/review`，管理同会话并发、取消、状态和独立报告保存。
- `src/snapshot.ts` 通过无 shell 的 Git 对象读取建立左右版本，工作区只读取普通文件；包含净变化、index、merge-base、第一父提交与空树语义。
- `src/runtime.ts` 创建无 seed 的 DSH Agent，沿用父 Agent 模型配置，在发布前配置完整系统提示词、native 工具呈现、空继承允许列表和 monotonic guard。模型仅能访问冻结内存快照。
- `src/report.ts` 提供中文审查标准、目标版本规则及 JSON/双侧定位/证据后置校验。
- `src/journal.ts` 使用插件目录内文件 flush 与原子替换保留最近报告；原会话仅使用宿主自身命令事件。

## 已核实的宿主契约

依赖明确固定 `@deepseek-ai/dsh-* 0.1.5-rc.2` 与 `@deepseek-ai/cordis 4.0.2`；不按 npm 默认标签推断版本。

1. `agents.create` 的 setup 在发布前完成，无 seed 不继承主会话历史。`AgentHandle.dispose` 等待循环停止并移除 scoped 能力。
2. `tools.restrict` 不足以封锁新增 scoped 工具；`tools.guard` 位于可扩展 pre-execute 后，拒绝结果不能被后续放行覆盖。测试中额外注册 scoped 工具与全放行 pre-execute，写入夹具仍未执行；PTC `run_code` 入口也被拒绝。
3. `whenIdle` 不是成功证明：实现核对本次用户消息、所属 turn/end 的 completed 原因、未中断的最终 assistant/message，模型错误和无效 JSON 分开显示。
4. rc.2 持久化 `validateStoredEvents` 拒绝未标记 ignorable 的外部事件，而公开 Session.append 不提供该标记。首版不写自定义会话事件，使用独立 JSON 记录，原生命令日志通过官方验证器。
5. `sessions.flush` 返回是否有监听器参与，不代表最终 UI 已显示结果；报告文件独立保存，原生命令结果由宿主 command/done 管理。真实远程 UI 断连重送尚未人工验收。

## 自动验证范围

- Git 临时仓库：新增、未跟踪、修改、纯删除、精确重命名、重复内容删除、目录替换、中文空格路径、暂存与工作区分离、历史上下文、分叉 merge-base、merge commit 第一父提交、无 HEAD、根提交、index 链接、冲突和二进制未覆盖。
- 报告：JSON 无效、证据与目标不一致、非 diff 位置；原子文件恢复和写入失败。
- 真实 DSH AgentLoop + 离线模型：主历史/普通提示词隔离、只读工具成功、全局/scoped/PTC 拒绝、有发现/零发现、模型失败、取消、超时、目标变化、启动/最终 flush 失败、重建 Context 恢复、卸载无残留。
- 打包：独立 DSH_HOME 安装 tgz、完整官方 peer 闭包、bundle 配置发现、打包后的同一宿主回归；验证目录在脚本 finally 中清理。

最终命令和数量在[迭代总览](00-迭代总览.md)记录。每项宿主测试的模型均为本地离线适配器，不是在线模型验收。
